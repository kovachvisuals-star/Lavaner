# LAVANER — виконані виправлення та контроль випуску (19.10.2026)

## Фактично змінено в GitHub (гілка direct-seo-2026-10-18, PR #5)
- Форма заявок: повідомлення ET/RU/EN більше не стверджують, що лист відправлено через `mailto:`. Людина повинна натиснути «Send» у пошті; прямий серверний режим позначає успіх лише після HTTP 201 від `/api/quote`.
- `generate_lead` залишено **лише для підтвердженого серверного отримання**; email fallback — окрема `email_click`. При помилці валідації/доставки окремий `form_submit_error`. Знято небезпечний псевдонім `form_submit -> generate_lead`.
- Додано запасний клікабельний телефон і e-mail у форму, позначку сторінки запиту для керівника, унікальні підписи/ID полів для кількох форм на сторінці.
- Точна цільова географія в UI, контактних/інформаційних текстах ET/RU/EN: Tallinn, Maardu, Viimsi, Harjumaa. Без непідтвердженої заяви «вся Естонія».
- OG: метадані відображають фото конкретної сторінки, для портфоліо — реальне фото завершеної ванної кімнати. Додано назву компанії для соціальних прев'ю.
- Organization/Service JSON-LD: додано Viimsi, усунено надмірне охоплення всієї держави; прибрано `sameAs` із непідтвердженим generic Google Search URL.
- Прозора ідентифікація: LAVANER OÜ, registrikood 12642198, перевірено: https://ariregister.rik.ee/eng/company/12642198. Код показується у футері та контактному блоці на ET/RU/EN, а також у Organization JSON-LD.
- Розширено вихідні статичні перевірки `site/scripts/validate-source.mjs`: події заявок, уникнення фальшивого `generate_lead`, унікальні поля та зона обслуговування.
- Збережено всі поточні URL/3 мови, фото замовника, логотип, бюджет без Google Ads.
